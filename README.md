# 2%Power

Android device monitor for battery, memory, storage, live system metrics, diagnostics and home-screen widgets.

## Build

Pushes to `main` trigger the Android CI workflow. Download the `2Power-debug-apk` artifact from the Actions run.

- Package: `com.krank.power`
- Version: 1.0 (versionCode 1)
- Min SDK: 23 (Android 6.0)
- Target SDK: 35
